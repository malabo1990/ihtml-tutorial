Cuando tu animación está lista, IHTML te da varias salidas. Elige según dónde se va a ver.

## Para la web: Export HTML

**Export HTML** abre un diálogo con dos opciones:

- **Single HTML file**: un solo `.html` autocontenido, con el motor de animación incluido. El más fácil de subir.
- **Separate HTML + CSS + JS**: tres archivos, útil si lo vas a integrar en tu web.

El resultado funciona en cualquier navegador y hosting, y también dentro de un `<iframe>` o un CMS. Anima exactamente igual que en el editor.

## Para enviar el proyecto: Export (.ihtml)

**Export** descarga `project.ihtml` con el proyecto completo: elementos, animaciones, acciones, fuentes, imágenes y vídeo.

- Quien lo recibe lo abre con **IHTML Mirror**, la app gratuita para escritorio y Android.
- Tú lo vuelves a abrir con **Import** para seguir editando.

> Un `.ihtml` no se abre con doble clic en el navegador. Si alguien debe verlo sin instalar nada, usa Export HTML.

## Imagen, GIF o vídeo

**Exportar imagen / GIF / video** convierte el artboard en una imagen fija (PNG, WebP, JPEG), un GIF animado o un vídeo (MP4, WebM). Eliges los FPS y la escala.

## Verlo en tu móvil

**Vista previa en el móvil** muestra un código QR: escanéalo con el teléfono y verás el proyecto en directo. Se recarga solo cuando editas.

## Planes

El plan **Gratis** exporta imagen fija. El plan **Completo** añade HTML, `.ihtml`, GIF, vídeo, Preview y la vista previa por QR. Consulta los precios en [ihtml.eu](https://ihtml.eu/es/#precio).

## Qué has aprendido

- Export HTML para publicar en la web.
- Export `.ihtml` para compartir el proyecto editable.
- Exportar imagen, GIF o vídeo, y verlo en el móvil.
